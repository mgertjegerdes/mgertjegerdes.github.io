# mgertjegerdes.github.io

Website for [Runell](https://mgertjegerdes.github.io/): the home page, support and privacy policy, in English and German (`de/`).

Plain HTML and CSS with relative links, served by GitHub Pages from `main`. No build step: edit the files and push. The app icon is rebuilt in CSS from the icon's runner artwork in `assets/runner.png`.

When the app's data flows or permissions change, update the privacy policy in both languages.
